# SKULL MALL 骷髅头潮品商城

一个以**骷髅（Skull）为主题**的暗黑哥特风购物网站演示站点，纯前端实现，双击 `index.html` 即可打开。

## 目录结构

```
骷髅头潮品商城/
├─ index.html      首页：骷髅轮播、10大分类、死亡折扣、四大楼层、骨头榜、新品空投
├─ list.html       单品列表：品牌/价格/材质/服务四重筛选 + 7 种排序 + 分页
├─ detail.html     单品详情：头骨图集、规格、数量、评价、参数、售后、同墓推荐
├─ cart.html       骨堆（购物车）：勾选、改量、抛弃、全选、合计、模拟献祭
├─ login.html      登录 / 注册（暗黑侧栏 + 验证码倒计时）
├─ user.html       个人中心：订单、优惠券、收藏、地址、骷髅币、账号设置
├─ css/style.css   全站暗黑哥特样式（响应式）
└─ js/data.js      数据层：10 系列 × 6 款 = 60+ 骷髅单品
```

## 页面主题设计

**视觉基调**：纯黑背景（#0b0c10）+ 骨白文字（#e8e6df）+ 血红点缀（#c1121f），配合毒素绿、暗金、幽紫作为标签色。所有商品图位用骷髅/骨/墓碑类字符作符号占位，统一灰度处理，hover 时泛血红辉光。

**贯穿全局的骷髅元素**：
- Logo 为骷髅徽记（💀），带血色辉光 hover 效果
- 每个区块标题前有 `☠` 前缀
- 商品卡片右下角有随机骷髅角标（💀 ☠ 🦴 ⚰️）
- 页面背景有 6 个缓慢飘浮的骷髅符号（`driftUp` 动画）
- 楼层横幅右侧有大号骷髅图标，斜纹背景
- 顶部有"死亡折扣进行中"闪烁预警
- 首页底部有 `MEMENTO MORI`（记住你终将死去）标语条

## 商品数据

10 大系列：骷髅T恤 / 连帽卫衣 / 骷髅饰品 / 骷髅箱包 / 骷髅摆件 / 骷髅鞋靴 / 暗黑家居 / 骷髅工具 / 纹身贴纸 / 黑胶潮玩，每系列 6 款共 **60+ 件单品**。

每件单品含：名称、品牌（SKULL LAB / OSSEOUS / GRAVE WALK / BONEHEAD / MORTIS 等 10 个暗黑潮牌）、材质（纯棉 / 钛钢 / 925银 / 树脂 / 皮革等）、价格、原价、销量、评分、库存、规格、服务标签、骷髅标语（MEMENTO MORI / REST IN PIECES 等）。数据使用固定种子伪随机生成，刷新不变。

## 功能说明

- **购物车真能用**：加购、改量、抛弃、勾选、算运费、算满减、模拟结算，数据存 localStorage（key `skull_cart_v1`），关掉浏览器再开还在。
- **筛选排序完整**：列表页支持品牌 / 价格区间 / 材质 / 服务四重筛选，综合、销量、新品、价格升降、折扣力度、好评度七种排序，带分页。
- **交互细节**：轮播自动播放可点切换、死亡折扣倒计时、加购 Toast、回到顶部、导航吸顶、数量限购 10 件。

## 使用方式

直接双击 `index.html`。若浏览器限制本地文件，可用本地服务器：

```bash
cd 骷髅头潮品商城
python -m http.server 8901
# 访问 http://127.0.0.1:8901
```

## 声明

本站为**演示站点**，所有商品名称、品牌、价格、评价、订单均为示例数据，无任何真实交易功能。登录 / 注册为模拟流程，不发送真实请求。
